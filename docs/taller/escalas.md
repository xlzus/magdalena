# :musical_keyboard: Escalas musicales (guía rápida)

Las **escalas** son el alfabeto de la música. Si conoces una escala, puedes entender mejor qué notas suenan bien juntas, cómo construir acordes y cómo transportar un canto con más seguridad.

Para empezar de forma práctica, esta guía usa la **escala mayor** (patrón: tono - tono - semitono - tono - tono - tono - semitono).

---

---

## Lectura práctica para coro

- En repertorio litúrgico, verás con más frecuencia tonalidades simples como **C, D, E, F, G, A y Bb**.
- Las notas con doble sostenido (`##`) o dobles alteraciones aparecen en teoría formal, pero rara vez en cantos sencillos.
- Si estás comenzando, estudia primero estas escalas: **C, G, D, A, F y Bb**.

## Constructor visual de acordes (por semitonos)

Piensa en cada acorde como una **fórmula de distancias** desde la nota raíz.

Regla base:

- La raíz es `0` semitonos.
- Cada nota del acorde se obtiene sumando semitonos.
- Una octava completa son `12` semitonos.

### Rueda cromática (12 semitonos)

Tomando **C** como referencia:

| Semitonos desde C | Nota       |
| ----------------- | ---------- |
| 0                 | C          |
| 1                 | C# / Db    |
| 2                 | D          |
| 3                 | D# / Eb    |
| 4                 | E          |
| 5                 | F          |
| 6                 | F# / Gb    |
| 7                 | G          |
| 8                 | G# / Ab    |
| 9                 | A          |
| 10                | A# / Bb    |
| 11                | B          |
| 12                | C (octava) |

La misma lógica aplica para cualquier raíz: solo cambias el punto de inicio.

### Fórmulas rápidas de acordes comunes (por grados)

| Tipo de acorde     | Fórmula por grados        | Semitonos (referencia) | Ejemplo en C       |
| ------------------ | ------------------------- | ---------------------- | ------------------ |
| Mayor (`C`)        | `I - III - V`             | `0 - 4 - 7`            | C - E - G          |
| Menor (`Cm`)       | `I - bIII - V`            | `0 - 3 - 7`            | C - Eb - G         |
| Sus2 (`Csus2`)     | `I - II - V`              | `0 - 2 - 7`            | C - D - G          |
| Sus4 (`Csus4`)     | `I - IV - V`              | `0 - 5 - 7`            | C - F - G          |
| Add2 (`Cadd2`)     | `I - II - III - V`        | `0 - 2 - 4 - 7`        | C - D - E - G      |
| Add9 (`Cadd9`)     | `I - III - V - IX`        | `0 - 4 - 7 - 14`       | C - E - G - D      |
| 7 dominante (`C7`) | `I - III - V - bVII`      | `0 - 4 - 7 - 10`       | C - E - G - Bb     |
| Maj7 (`Cmaj7`)     | `I - III - V - VII`       | `0 - 4 - 7 - 11`       | C - E - G - B      |
| m7 (`Cm7`)         | `I - bIII - V - bVII`     | `0 - 3 - 7 - 10`       | C - Eb - G - Bb    |
| 9 dominante (`C9`) | `I - III - V - bVII - IX` | `0 - 4 - 7 - 10 - 14`  | C - E - G - Bb - D |

Convenciones rápidas:

- `b` antes del grado significa que esa nota baja medio tono (ejemplo: `bIII`).
- `#` antes del grado significa que esa nota sube medio tono.
- `II` y `IX` son la misma nota por nombre, pero `IX` indica función extendida (pensada una octava arriba).

### Regla visual para construir cualquier acorde

1. Elige la raíz.
2. Busca su posición en la rueda de 12 semitonos.
3. Suma cada número de la fórmula.
4. Si te pasas de 12, resta 12 (o sigue contando en la octava siguiente).

Ejemplo rápido con **A minor (Am)**:

- Fórmula menor: `I - bIII - V` (semitonos: `0 - 3 - 7`)
- Desde A: `I = A`, `bIII = C`, `V = E`
- Resultado: **A - C - E**

Ejemplo rápido con **G7**:

- Fórmula 7 dominante: `I - III - V - bVII` (semitonos: `0 - 4 - 7 - 10`)
- Desde G: `I = G`, `III = B`, `V = D`, `bVII = F`
- Resultado: **G - B - D - F**
