# Ministerio Parroquial Santa María Magdalena

Bienvenidos al cancionero oficial del **Ministerio Parroquial Santa María Magdalena**.

Este espacio reúne las letras y acordes de los cantos que acompañan nuestra celebración litúrgica, organizados por el momento de la misa en que se interpretan.

---

## ¿Qué encontrarás aquí?

Cada sección corresponde a un momento de la celebración eucarística:

| Momento                                        | Descripción                                |
| ---------------------------------------------- | ------------------------------------------ |
| **Entrada**                                    | Cantos de acogida y procesión inicial      |
| **Señor, ten piedad**                          | Acto penitencial                           |
| **Gloria**                                     | Himno de alabanza                          |
| **Aleluya**                                    | Aclamación al Evangelio                    |
| **Ofertorio**                                  | Cantos durante la presentación de dones    |
| **Santo**                                      | Aclamación antes de la consagración        |
| **Consagración**                               | Cantos de adoración eucarística            |
| **Cordero de Dios**                            | Fracción del pan                           |
| **Comunión**                                   | Cantos de recepción                        |
| **Salida**                                     | Envío final                                |
| **Hora Santa**                                 | Cantos de adoración eucarística prolongada |
| **Adviento / Pascua / Pentecostés / Trinidad** | Repertorio de tiempos litúrgicos           |

---

## ¿Cómo usar este cancionero?

- Usa el **menú lateral** para navegar entre secciones.
- Cada página contiene la **letra completa** y los **acordes** del canto.
- Puedes usar el botón de **búsqueda** (arriba a la derecha) para encontrar un canto por su nombre.
